# WW1 Tower Defense

一战题材 2D 塔防游戏，使用 Godot 4.6 引擎开发。德军沿三条路线进攻，法军机枪阵地坚守马恩河防线。

## 运行方式

windows用户点击WW1 Tower Defense.exe即可运行
Linux用户点击WW1 Tower Defense.x86_64即可运行

无需额外依赖或构建步骤。

## 游戏玩法

- **建造防御**：点击底部按钮放置机枪阵地（100g）或火炮（150g）
- **升级塔**：点击已放置的塔查看升级/出售面板，最高 3 级
- **开始波次**：点击"Start Wave"开始敌军进攻
- **速度控制**：右上角 1x/2x 切换游戏速度

### 敌人类型

| 敌人 | 特性 |
|------|------|
| Elite Soldier | 基础步兵，速度快 |
| Tank | 重型装甲（6 护甲），高血量 |
| Airplane | 高速飞行，无护甲 |
| Zeppelin | 巨型飞艇，极高血量 |
| Flamethrower | 中等属性，中后期出现 |

### 塔属性

| 等级 | 伤害 | 射速 | 射程 | 升级费用 |
|------|------|------|------|----------|
| Lv1 | 15 | 0.5s | 250px | 100g |
| Lv2 | 30 | 0.4s | 280px | 150g |
| Lv3 | 50 | 0.3s | 320px | 250g |

## 项目结构

```
├── scenes/          # 场景文件（.tscn）
├── scripts/         # GDScript 脚本
├── assets/          # 游戏资源（纹理、UI、字体）
│   ├── enemies/     # 敌人精灵
│   ├── towers/      # 塔精灵
│   └── ui/          # UI 元素
├── art/             # 原始高清美术资源
├── music/           # 背景音乐
├── project.godot    # 项目配置
```

## 操作

| 操作 | 按键 |
|------|------|
| 放置塔 | 点击按钮后点击地图 |
| 取消放置 | Esc / 右键 / Cancel 按钮 |
| 选择塔 | 点击已放置的塔 |
| 升级/出售 | 选中塔后点击面板按钮 |
| 开始波次 | 点击 Start Wave |
| 暂停/加速 | 右上角 1x/2x |

## 游戏资产说明

本项目图片资产系image2和banana2生成，音乐资产使用Battlefield 1 ™部分游戏配乐。
